# 4. 状态机视角理解数列求和电路
数列求和电路用到了两个加法器和两个4位寄存器，因此电路初始状态为PC和SUM两个寄存器的初值，状态机迭代规则为(***并行计算不分先后***):  
`PC = PC + 1`  
`SUM = SUM + PC`

    (0000,0000)  # 寄存器初始状态
    (0001, 0000)  # PC = PC + 1 = 1    SUM = SUM + PC = 0
    (0010, 0001)  # PC = PC + 1 = 2    SUM = SUM + PC = 1
    (0011, 0011)  # PC = PC + 1 = 3    SUM = SUM + PC = 3
    ......
    (0010, 0001)  # PC = PC + 1 = 6    SUM = SUM + PC = 15
    (0010, 0001)  # PC = PC + 1 = 7    SUM = SUM + PC = 5(溢出)
    (0010, 0001)  # PC = PC + 1 = 8    SUM = SUM + PC = 12
可以注意到保存结果的四位寄存器一旦溢出，后续的迭代计算都将全部错误
# 5. 理解编译器工作
C程序语句`sum = sum + i`编译为指令码有如下操作:
1. 为变量sum和变量分配内存空间或指定寄存器；
2. 分配完毕后，指定迭代规则为两个寄存器结果送进加法电路；
3. 加法电路写回sum对应的内存(寄存器)

我对讲义的个人理解是：
>计算机运行过程可以抽象 = 初始状态 + 迭代法则 + 激励序列(机器码)

但是由于冯诺依曼架构机器码放在内存，内存又是状态集合的一部分，所以上述等式可精简描述为：
>计算机运行过程 = 初始状态 + 迭代法则。  

更精简的数学描述为:
$S_\text{next}=F(S_\text{current})$

如何设计这个迭代法则F，就是计算机组成原理和体系结构要解决的问题
