# 1. 实现取指功能
根据sCPU的指令结构以及PC位宽，ROM寻址空间设计为2^4 = 16，指令字长8位。所以ROM空间为16 X 1Byte,可以用4-16选择器实现




# 2. 实现GPR写入
仅当为add或li指令允许开启寄存器回写，回写数据来源为8位加法器结果和imm立即数

# 3. 实现li指令
li指令既读又写，PC更新策略为+1，读数据来源为指令码的imm位，写数据目的地为指令码的rd寄存器。

# 4. 更新PC
PC的更新策略只有自增PC = PC+1，以及跳转指令bner0导致的跳转，PC数据来源为PC计数器输出，或bner0指令码中的addr。PC的写数据目的地为PC寄存器自身。

# 5. 添加add指令
add指令既读又写，PC更新策略为+1，读数据来源为指令码的rs1,rs2寄存器，写数据目的地为rd寄存器

# 6. 添加bner0指令
bner0指令只读不写，PC更新策略为指令码中的addr，数据来源为rs2寄存器和r0寄存器，除了更新PC外不回写寄存器组。

# 7. 计算10以内的奇数和
设置寄存器循环计数r0 = 11，初值r1 = 1, 步长r3 = 2;

    10001011    # 0: li r0, 11
    10010001    # 1: li r1, 1
    10100000    # 2: li r2, 0
    10110010    # 3: li r3, 2
    00010111    # 4: add r1, r1, r3
    00101001    # 5: add r2, r2, r1
    01001000    # out r1
    11010001    # 6: bner0 r1, 4
    11100011    # 7: bner0 r3, 7

# 8. 添加out指令
out指令只读不写，PC更新策略为+1，读数据来源为指令码的rs1寄存器，只改变外设数码管状态，不回写寄存器组。

# 9.感悟随笔
动手实现遇到了很多问题，例如一些状态逻辑的混淆，程序不从ROM地址为0开始，插入IR寄存器后解决了但电路跑一会就崩了，书上提到的数据冒险问题，真书上讲百遍不如自己遭遇一遍。
这节讲义最大的收获还是任何指令设计定义之前，务必一定要对它的数据来源，数据去哪，对关键寄存器例如PC，GPR，甚至整个状态集合会造成怎样的影响，务必把思路框架清楚后再设计可以减少很多调试的痛苦。
