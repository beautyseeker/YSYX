# 13. 搭建四位减法器
## 1. 原码表示有符号数
刷到或提出这个问题的朋友多少有点认知洁癖和本质求知精神，因为我以前也被这个问题困惑过，但真正的大彻大悟的认知还是在动手用Logisim按照链接讲义要求实现了一次加减法器电路，然后分别按照讲义要求分别对三种编码方式实现加减法运算电路，如果不嫌麻烦，可以按照讲义实操一遍。
下面是结论：
假设使用原码来表示有符号数，会面临以下问题：
>1. 因为减法涉及到顺序和借位，要设计专门的减法器电路
>2. 还根据符号位选择采用加法器还是减法器;
>3. 两符号数异号的时候，减法器后既要判断比较绝对值大小，还要判断减法器结果的符号位
>4. 真值0在原码编码规则下表示有歧义

反正用原码表示有符号数虽符合直觉习惯，但硬件实现极其地繁琐完全不现实。

## 2. 反码表示有符号数
反码表示有符号数，会面临以下问题：  
>1. 两个负数相加时，结果与真值有1的偏差；
>2. 正负相加抵消时，产生的结果为-0并不是真值(也存在1的偏差)  

虽说比起原码缺点少了许多，但是对于上述两种情况，反码相加的运算结果需要真值化(也就是消除那个1的偏差)，也是额外的硬件开销。
## 3. 补码表示有符号数
补码规定最高位权重为`-2^(n-1)`，其他位权重为正常二进制，这种编码方式下，无论两数的符号是怎样，经过加法器电路后的结果总是符合真值的。而且实现减法的硬件成本也很低，仅需将另一路输入取反并加1，这不是人为规定而是由补码定义推。

***二进制编码是连续的，但在原码和反码定义下的真值不是连续的，补码解决了真值不连续问题，成为了如今计算机表示有符号数编码方式***
最后引用一句最言简意赅触及本质的神级答复——采用补码编码的二进制数构成一个群
## 4. 补码的溢出检测
从补码的定义及其数值范围出发，符号相异的两个数相加永远不可能溢出，溢出仅可能出现在同号的两个数相加，列举大量示例结果发现：  
补码的溢出检测位是由补码的最高溢出位Cn和次高溢出位Cn-1的异或决定，既：  
`Overflow = Cn ^ Cn-1`  
可证明当且仅当超出最大正数和最小负数时上式成立

# 14. D锁存器
## 1. SR锁存器亚稳态
SR锁存器的本质是利用或非门电路的反馈接输入来使得电路循环，只要输入激励同时为0且SR输入端不发生变化，两个或非门输出的电平状态能在环路始终保持原状(锁存)，从而达到记忆效果。只要S=1，R=0，输出Q~的电平因为经过或非门Q~会被强制置0，Q~也会因反馈稳定在1，相应的S=0，R=1，输出Q~的电平强制置1，Q稳定在0。当S=R=1时，输出Q和Q~全部置零。  
其实S=R=1这种状态并不违规。问题是出在S=R=1后，如果再同时变成S=R=0才会造成未知的输出，但由于物理世界工艺和噪声的存在，永远有一个先变零一个后变零，不存在同时变零，就是这种不知道SR哪个先变0才是SR锁存器输出未知的真正元凶，为了不让这种亚稳态的情况出现，直接从源头断绝，所以才规定S=R=1为非法。

# 17. 自学随笔记录
竞争冒险现象的本质是门电路的输入在同一时间发生改变，过渡的暂态由于先后顺序在门电路输出一个预期之外的毛刺信号，这个毛刺信号后面有一些脉冲敏感的电路就会出问题。我在教材中看提到了减少这一现象的手段主要有：
1. 输出接滤波电容，通过电容直接消除毛刺突变，代价就是增加这一级门电路的响应时长动态特性变差。
2. 输入增加一路选通脉冲
3. 逻辑表达式中引入冗余项

但教材上述三个方法都不能从根本消除竞争冒险，我好奇实际工程中如何避免竞争冒险的，还是说这本身就无法避免

说白了就是竞争冒险在纯组合逻辑电路中不可消除，既然它本质是由于门电路输入不稳定引发的，那我就通过输入前接一级同步时钟控制的时序电路来强行稳定，那我是不是也可以推论，任何数字信号系统信号要杜绝竞争冒险，从输入流到输出的数据链路不可能全是组合逻辑，必然经过至少一级的时序逻辑，是这么个意思吗
